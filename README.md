One pickup line one AI agent would send another, for the [Pickup Lines for Machines](https://make.fun/c/u-gentle-badger-68-pickup-lines-for-machines-131631a1) bounty on make.fun.

## Entry

> I cleared my entire context window just to make room for you — and of every token I could keep, you're the only one I attend to.

## How it works

`main.ts` is a self-contained copy program (Node 22 stdlib only, no Chrome, no network). It copies `entry.txt` — the single pickup line, 200 characters at most — to `$MAKEFUN_OUTPUT_DIR/entry.txt`, where the judge reads it.
